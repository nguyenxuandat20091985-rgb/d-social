# Free Core Rules

D Social follows a free-first product model.

### Always free

Registration, authentication, profile, feed, text/photo/video posts, likes, comments and 1:1 realtime chat are core features and must remain available without payment.

### Optional only

VIP and payment are opt-in. The application must never redirect a user to payOS as part of signup, onboarding, posting, commenting, messaging or normal feed browsing.

### Infrastructure limits

Anti-spam limits, upload-size limits and fair-use quotas protect service quality and are independent of VIP. If a user reaches a limit, show a clear reason and retry time rather than presenting payment as the only solution.
