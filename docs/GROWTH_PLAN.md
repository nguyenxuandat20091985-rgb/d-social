# D Social — Sustainable Growth Roadmap

## Phase 1: Free core

Focus on onboarding, fast feed, media posting, likes/comments, profile and realtime 1:1 chat. No payment wall.

## Phase 2: Safety and reliability

Move abuse limits from browser-only helpers to trusted server/database enforcement. Add reports, blocks, moderation queues, audit logs and operational alerts.

## Phase 3: Performance at scale

Use cursor pagination for very large feeds, image resizing/thumbnails, video transcoding, CDN caching, bounded realtime subscriptions, database query monitoring and load testing.

## Phase 4: Optional VIP

Expose VIP only from an explicit profile/wallet entry point. Keep the free core unchanged. Start with cosmetic/convenience benefits and transparent pricing.

## Product metrics

Track activation, D1/D7/D30 retention, posts per active user, meaningful conversations, report rate, moderation response time, feed latency and crash/error rate. Treat payment conversion as a secondary metric until organic retention is healthy.
